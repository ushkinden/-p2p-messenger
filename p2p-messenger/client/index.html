Прямая связь

Сообщения идут напрямую между устройствами. Ничего не хранится на сервере — только у вас на устройстве.

Это адрес лёгкого сервера, который просто помогает устройствам найти друг друга. Сам он переписку не хранит и не читает. Инструкция по запуску — в README проекта.
